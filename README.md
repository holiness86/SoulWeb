# 🌐 Soul Web Admin Panel

<p>
  <img src="https://img.shields.io/badge/Node.js-Express-green?logo=node.js" alt="Node.js" />

یک پنل مدیریت کامل برای آژانس Soul Web؛ شامل مدیریت پروژه، فاکتور، نمونه‌کار و بلاگ.

</div>

---

## ✨ ویژگی‌ها

- 📁 مدیریت پروژه‌ها با تقویم شمسی (Jalali)
- 🧾 صدور و مدیریت فاکتور با خروجی PDF
- 🖼️ گالری نمونه‌کارها (Portfolio)
- ✍️ بخش بلاگ با ادیتور کامل
